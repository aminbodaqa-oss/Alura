# لاندنج بيدج + لوحة تحكم + SQLite

## التشغيل
1. ثبّت Node.js 22.13 أو أحدث.
2. داخل المجلد: `node server.js`
3. الموقع: http://localhost:3000  — لوحة التحكم: http://localhost:3000/admin
4. أول مرة تفتح /admin هتعمل حساب الأدمن (اسم مستخدم + كلمة مرور). بعدها بيبقى تسجيل دخول عادي.

## الملفات
- server.js : السيرفر (بدون مكتبات) + إنشاء ملف قاعدة البيانات data.db تلقائياً
- public/index.html : الصفحة الرئيسية (مفيهاش أي رابط للوحة التحكم)
- public/admin.html : لوحة التحكم
- public/shared.js : القيم الافتراضية ودوال مشتركة

## data.db (SQLite)
جداول: admin (الحساب بكلمة مرور مشفرة scrypt) - settings (كل إعدادات الصفحة) - orders (الطلبات) - sessions

## متغيرات اختيارية
PORT=8080  |  ADMIN_PATH=/my-secret-panel (غيّر مسار اللوحة)  |  WHATSAPP=رقم احتياطي

## للنشر على الإنترنت
استخدم HTTPS (Nginx/Caddy أو خدمة استضافة Node) واحتفظ بنسخة احتياطية من data.db.

## المميزات الإضافية
- الباقات + الشحن حسب المحافظة (الحساب بيتم على السيرفر، العميل مش بيقدر يغيّر السعر)
- حالة كل طلب + بحث + فلتر + تصدير Excel (CSV) + إحصائيات
- إشعار تليجرام لكل طلب جديد (من تبويب "إشعارات تليجرام")
- بكسل فيسبوك / تيك توك / Google Analytics
- تقييمات، أسئلة شائعة، شريط ثقة، عدّاد مخزون، فيديو يوتيوب
- الصور بتتحفظ كملفات في مجلد uploads/، ونسخة احتياطية يومية من data.db في مجلد backups/ (آخر ١٤ يوم)
- معاينة المشاركة (عنوان ووصف وصورة) بتتولّد على السيرفر
- حماية من السبام: حقل مصيدة + منع تكرار نفس الطلب خلال ١٠ دقايق
